Portal de notícias sobre tecnologia desenvolvido com **HTML** e **CSS** como projeto do curso da **[Rocketseat](https://www.rocketseat.com.br/)**.

O objetivo foi praticar a construção de um layout completo e responsivo, com foco em **CSS Grid** e organização de código.
